# Machine Learning / Deep Learning Specialist

Repositório de aprendizado da formação Machine Learning / Deep Learning Specialist da DIO. Cada desafio reúne código, instruções de execução e espaço para documentar os experimentos realizados durante o curso.

## Como começar

1. Acesse o desafio na tabela abaixo.
2. Abra o notebook no Google Colab e selecione um ambiente com GPU.
3. Execute as células em ordem e analise os resultados.
4. Registre as configurações, métricas e conclusões obtidas no README do desafio.

O treinamento será executado no **Google Colab**. Não é necessário instalar dependências ou baixar datasets na máquina local.
